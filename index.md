# Last Light Privacy Policy

**Effective date: September 20, 2026**

Last Light is developed and published by **Last Light Game Studio**.

This Privacy Policy explains how the current version of Last Light handles user information.

## Information We Collect

The current version of **Last Light does not collect, transmit, sell, or share personal information or user data**.

The game currently does not use:

- user accounts or sign-in;
- advertising services;
- analytics services;
- crash-reporting services that transmit user data;
- cloud saves;
- social-network integrations;
- location tracking;
- advertising identifiers;
- external marketing or attribution SDKs.

## Local Game Data

Last Light stores gameplay data locally on the user's device in order to provide normal game functionality.

This may include information such as:

- game progress;
- character progress;
- inventory and equipment;
- quest and story progress;
- game settings;
- local save-game information.

This data remains on the user's device and is not transmitted to Last Light Game Studio or third parties by the current version of the game.

Removing the application or clearing its application data may permanently remove locally stored game progress.

## Internet Connection

The current version of Last Light does not require an online account or online game service for normal gameplay.

Google Play may independently process information related to downloading, installing, updating, purchasing, or operating applications through Google Play. Such processing is governed by Google's own privacy policies and is outside the control of Last Light Game Studio.

## Payments

The current version of Last Light does not contain in-app purchases.

If purchases, online services, accounts, analytics, advertising, cloud saves, or other network features are introduced in a future version, this Privacy Policy and the Google Play Data Safety declaration will be updated before or alongside those features.

## Children's Privacy

Last Light is not designed or marketed specifically for young children.

The game contains post-apocalyptic themes, combat, violence, and other mature content. The appropriate age rating may vary by country or rating authority.

The current version does not knowingly collect personal information from children or other users.

## Data Sharing

Because the current version of Last Light does not collect personal user data, Last Light Game Studio does not sell or share personal data with third parties.

## Data Security

The current version does not maintain a remote database containing player personal information or gameplay data.

Gameplay saves are stored locally on the user's device.

## Changes to This Privacy Policy

This Privacy Policy may be updated as Last Light develops.

If future versions introduce features that collect, transmit, or share user data, this policy will be updated to describe:

- what data is collected;
- why the data is collected;
- how the data is used;
- whether the data is shared;
- how the data is protected;
- what choices users have regarding their data.

The latest version of this Privacy Policy will remain available at this page.
